\section{Dashboard}

GIO dient hauptsachlich der Visualisierung von Daten für Mitarbeiter:innen 
damit diese schnell und einfach den Zustand der Infrastruktur erkennen können. 
Die Visualisierung erfolgt über ein Dashboard, 
das die gesammelten Daten in einer übersichtlichen und interaktiven Form darstellt. 
Das Dashboard bietet verschiedene Funktionen, die es den Benutzer:innen ermöglichen, 
die Informationen nach ihren Bedürfnissen zu filtern und zu analysieren.

\subsection{Panels}
Auf dem Dashboard werden Informationen in Panels rechts auf dem Bildschirmrand dargestellt.
\begin{compactitem}
    \item \textbf{Statistiken:} Dieses Panel zeigt die Gesamtzahl der Standorte an, die in GIO erfasst sind. 
    Auch werden die aktiven Standorte angezeigt. 
    Als letztes wird die Anzahl der unterschiedlichen Länder in denen sich die Standorte befinden angezeigt.
    \item \textbf{Einstufungsquellen:} Dieses Panel zeigt die unterschiedlichen Einstufungsquellen an.
    Damit können die Benutzer:innen schnell eine Auswahl treffen, welche Einstufungsquelle sie auf dem Dashboard sehen möchten.

    \begin{compactitem}
        \item \textbf{\gls{sdwan}:} Dieses Panel zeigt an ob es ein Problem mit der \gls{sdwan}-Verbindung gibt.
        \item \textbf{\gls{hci}:} Dieses Panel zeigt an ob es ein Problem mit der \gls{hci} Resource gibt.
        \item \textbf{Server:} Dieses Panel zeigt an ob es ein Problem mit der Server-Verbindung gibt.
        \item \textbf{LAN:} Dieses Panel zeigt an ob es ein Problem mit der LAN-Verbindung gibt.
    \end{compactitem}

    \item \textbf{Filter:} Dieses Panel zeigt nur die Standorte an, die bestimmte Kriterien erfüllen.
    
    \begin{compactitem}
        \item \textbf{Nur aktive Standorte:} Dieser Filter zeigt nur die aktiven Standorte an.
        \item \textbf{Hat \gls{hci}:} Dieser Filter zeigt nur die Standorte an, die eine HCI Resource lagern haben.
        \item \textbf{Klassifikation:} Dieser Filter zeigt nur die Standorte an, die eine bestimmte Klasse haben. 
        Dieser Filter ermöglich eine Mehrfachauswahl damit können mehrere Filter gleichzeitig angewendet werden.
        
        \begin{compactitem}
           \item \textbf{-:} Dieser Filter zeigt alle Standorte an. Das ist der Standardfilter.
           \item \textbf{Cloud Hub:} Dieser Filter zeigt nur die Standorte an, die ein Cloud Hub sind.
           \item \textbf{HUB:} Dieser Filter zeigt nur die Standorte an, die ein HUB sind.
           \item \textbf{Large Site (FMO):} Dieser Filter zeigt nur die Standorte an, die eine Large Site (FMO) sind.
           \item \textbf{Medium Site (FMO):} Dieser Filter zeigt nur die Standorte an, die eine Medium Site (FMO) sind.
           \item \textbf{Small Site (FMO):} Dieser Filter zeigt nur die Standorte an, die eine Small Site (FMO) sind.
           \item \textbf{Remote Site (FMO):} Dieser Filter zeigt nur die Standorte an, die eine Remote Site (FMO) sind.
           \item \textbf{Special Site Cloud:} Dieser Filter zeigt nur die Standorte an, die eine Special Site Cloud sind.
           \item \textbf{Special Site DC:} Dieser Filter zeigt nur die Standorte an, die eine Special Site DC sind.
        \end{compactitem}
        \todo{Hier müssen noch die Klassen referenziert werden.}

        \item \textbf{Kritikalität:} Dieser Filter zeigt nur die Standorte an, die eine bestimmte Kritikalität haben.
        Dieser Filter ermöglich eine Mehrfachauswahl damit können mehrere Filter gleichzeitig angewendet werden.

        \begin{compactitem}
            \item \textbf{Stabil:} Dieser Filter zeigt nur die Standorte an, die stabil sind.
            \item \textbf{Instabil:} Dieser Filter zeigt nur die Standorte an, die instabil sind.
            \item \textbf{Kritisch:} Dieser Filter zeigt nur die Standorte an, die kritisch sind.
        \end{compactitem}
        \todo{Hier muss noch eine Beschreibung für die Zustände hinzugefügt werden.}

    \end{compactitem}
    
    \item \textbf{Legende:} Dieses Panel zeigt die Legende der Icons~\ref{subsec:icons} an, die auf der Weltkarte verwendet werden.

\end{compactitem}

\subsection{Gerätestatus}

Da die Geräte an den Standorten unterschiedliche Zustände haben können,
werden diese Zustände durch unterschiedliche Farben der Icons dargestellt.
Diese Farben geben den Benutzer:innen einen schnellen Überblick über den Zustand der Geräte an den Standorten.
Der Status der Geräte kann dabei in drei Kategorien unterteilt werden:
\begin{compactitem}
    \item \textbf{Grün:} Das Gerät ist in einem guten Zustand und funktioniert einwandfrei.
    \item \textbf{Gelb:} Das Gerät hat einen Warnstatus, der auf ein mögliches Problem hinweist.
    \item \textbf{Rot:} Das Gerät hat einen kritischen Status, der auf ein ernsthaftes Problem hinweist.
\end{compactitem}

\subsection{Cloud Hubs}
\label{sec:cloudhubs}

Cloud Hubs nehmen bei der Darstellung auf dem Dashboard eine Sonderstellung ein.
Im Gegensatz zu den übrigen Standorten werden sie unabhängig von der aktuell
verwendeten Detailebene immer auf der Karte angezeigt. Ihre Sichtbarkeit hängt
